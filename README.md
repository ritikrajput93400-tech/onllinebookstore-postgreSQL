# 🛒 Online Bookstore Database (PostgreSQL)
**📚 Online Bookstore Database (PostgreSQL)**

**📘 Description**
This project is a PostgreSQL-based relational database system designed to manage an online bookstore. It efficiently stores and organizes data related to books, customers, and orders while maintaining relationships between different entities. The system ensures data integrity, supports query-based analysis, and simulates real-world e-commerce operations.

**⚙️ Key Features**

* Structured database design using relational tables
* Management of books, customers, and orders
* Implementation of primary and foreign key relationships
* Efficient data retrieval using SQL queries
* Real-world database schema for an online store

**📂 Files Included**

* `onlinebookstore.sql` — Contains database schema, table creation scripts, sample data, and relationships

**💡 How to Restore / Run the Project**

1. Open pgAdmin
2. Create a new database named **onlinebookstore**
3. Open the Query Tool
4. Load the file `onlinebookstore.sql`
5. Execute the script to create tables and insert data

**🛠️ Technologies Used**

* PostgreSQL
* SQL

**🎯 Use Case**
This project can be used for learning database design, practicing SQL queries, and understanding how real-world e-commerce databases function.
