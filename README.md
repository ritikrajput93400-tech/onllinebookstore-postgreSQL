# 🛒 Online Bookstore Database (PostgreSQL)

### 📘 Description
This project is a PostgreSQL-based database system for managing books, customers, and orders.

### 📂 Files
- `onlinebookstore.sql` — Contains all database tables, data, and relationships.

### 💡 How to Restore
1. Open pgAdmin
2. Create a new database named `onlinebookstore`
3. Go to Query Tool → open `onlinebookstore.sql`
4. Run the script
